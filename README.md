# Soap4Me for macOS — updates

This repository distributes signed, notarized Soap4Me builds and the Sparkle update feed. It does not contain the application source code.

Download the newest `Soap4Me-*.zip` from [Releases](https://github.com/nearlynydev/soap4me-updates/releases/latest), extract `Soap4Me.app`, and move it to Applications. Version 0.1.7 is the first version with built-in updates; after installing it once, use **Soap4Me → Check for Updates…** or let the app check automatically.

Requirements: macOS 14 or newer on Apple Silicon. Soap4Me is an unofficial client and is not affiliated with Soap4u.
